# Min-Distance

Hallar la distancia euclidiana mínima entre 2 puntos en el plano, usando herramientas de análisis de algoritmos.

2025-1

### Instrucciones de compilación:
En el directorio /src se encuentran dos programas posibles para compilar: *main.cpp* y *euclidianv2.cpp*. El primero consta de las primeras implementaciones de *brute_force* junto al algoritmo implementado con el paradigma divide and conquer.

### Main
Para compilar main.cpp, abrir la terminal en el directorio src y ejecutar el siguiente comando: 
```
g++ main.cpp euclidian.cpp -o main
./main
```
Se pueden cambiar los puntos (x,y) modificando el propio código.

### Euclidianv2

Para compilar euclidianv2, simplemente ejecutar en el mismo directorio
```
g++ euclidianv2.cpp -o euclidianv2
./euclidianv2
```

Al igual que en main, se pueden modificar los puntos (x,y).

Para mayor flexibilidad y probar con pares de números aleatorios, dirigirse al directorio "leito". En él se puede utilizar el programa uhr.cpp para testear los algoritmos. Para mayor información visitar el repositorio https://github.com/leonardlover/uhr.
